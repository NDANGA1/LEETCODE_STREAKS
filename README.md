# LeetCode Streaks

My ongoing record of daily LeetCode problem-solving — currently past a **150+ day streak (2026)** — kept as a running log of solutions rather than a polished library, so it reflects real, consistent practice rather than a cleaned-up highlight reel.

## What's In Here

Python solutions spanning a wide range of topics and difficulty levels, including:

- Arrays & strings (subarray detection, string transformations)
- Dynamic programming & greedy problems
- Graphs & linked lists (e.g. Pacific Atlantic Water Flow, merging sorted linked lists)
- Stacks & queues (e.g. Reverse Polish Notation evaluation)
- Simulation-style problems (e.g. Simple Bank System, Leetcode Bank money calculation)

Each file is named after the problem it solves, making it easy to browse by topic.

## Why This Exists

Competitive programming practice sharpens the same skills that matter in AI/ML engineering: breaking a problem down, reasoning about complexity, and writing correct code under constraints. This repo is where I keep that habit visible and consistent.
